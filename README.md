# Smart Parcel Delivery Assistant

An interactive Design Thinking prototype for clearer parcel delivery and collection.

## Publish with GitHub Pages

1. Create a new empty GitHub repository named `smart-parcel`.
2. Upload the contents of this folder, including the hidden `.github` and `.nojekyll` files, to the repository's `main` branch.
3. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build source.
4. Open the **Actions** tab and wait for **Deploy Smart Parcel to GitHub Pages** to finish.
5. GitHub will display the public site address, normally `https://YOUR-USERNAME.github.io/smart-parcel/`.

Every later push to `main` publishes the latest version automatically.

## Local preview

From this folder, run:

```powershell
python -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.
